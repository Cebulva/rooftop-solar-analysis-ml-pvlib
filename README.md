# sunnai
An AI-powered Solar Planner using Computer Vision and pvlib to detect rooftops from satellite imagery, calculate precise financial payoff based on historic solar data, and provide a live dashboard for real-time analysis.

# map folder
free_downloader.py contains functions to download satellite images based on coordinates
solar_analysis.py contains functions from pvlib for solar output analysis
map_interface contains interface for maps and analysis for streamlit

update envionment before executing.
